Token Radar ranks pre-token protocols by implied value and gives each a concrete farm plan, from a sealed DefiLlama snapshot of 758 protocols. 178 ranked protocols, 40/40 watchlist coverage, 8 farm steps per row, plus a sortable and filterable dashboard with a detail view and a live view of 24 tokenized protocols.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input ../input/snapshot.json
```
